Build 227 applies the match-specific ranking to the ordinary initial Watch action. A source that sustained advancing native playback over the existing 90-second observation window ranks above one that only started. Later trouble on the same tap overrides the earlier start. While a competing provider is still looking, a previously failed route alone cannot win by arriving first. The existing deadline bounds that wait. Match evidence is specific to the same executable delivery and is held in memory for up to six hours.
