# Build 191 shared broadcast registry gate

30 October 2026. Owner-approved objective: a maintained shared catalog from
official fixtures and all enabled reviewed sources, with genuine fixture-bound
broadcast choices and Jet iPad acceptance. Phone, FPL and multi-stream stay
unchanged. No TestFlight. This plan does not assert a completed build, cloud
deployment, installation or decoded playback.

## Candidate scope

- Add one metadata-only cloud `BroadcastRegistry` Durable Object using existing
  accepted Sports/Cricket snapshots and seven reviewed collectors: StreamEx,
  Score808, CS, AS, CNC, Flix-Streams and StreamViX.
- Persist source observations, scope health, finite rejection reasons and
  explicit canonical fixture links. Keep partial/failing providers independent.
- Reuse the existing five-minute cron as a due check, max two providers per
  batch, bounded 15-second alarm continuation, persisted actual-read budgets,
  adaptive cadence and backoff. No Mac/Codex/AI routine collector.
- Read the common snapshot natively, preserve local opt-ins, and use admitted
  associations to resolve the exact current advertised source identity through
  each existing guarded adapter. Keep normal Watch and the existing picker.
- Retain four-hour listing facts without renewing 90-second binding metadata,
  60-second cached candidate sessions, session expiry or transport authority.
- Keep unresolved CNC hashes, malformed/undated rows, Test authority gaps and
  missing programme UTC semantics explicit. Do not turn unknown into Watch.

## Ordered acceptance

1. **Freeze and offline verification.** Root reviews the exact source diff and
   protected FPL/multi inputs, then runs sequential backend and native gates.
   Cover bounded schema/privacy, alias/squad/time conflicts, source-specific
   same-ID execution, source expiry, terminal/rescheduled fixtures, partial and
   failed sibling retention, clock rollback, durable reservations, disable fences,
   duplicate alarm/cron, capacity rejection, OFF/invalid configuration, GET-only
   public access and no outbound collection from GET. Root records exact final
   test totals and any skips after execution.
2. **Resolve real metadata blockers.** Require an actual admitted dated source
   link for a fresh target fixture; missing dates, malformed identity, closed
   primary-family profiles or stale Test day stay unresolved. Official lookup
   hints may select metadata to read but never supply a missing provider date.
   No generic-channel or LIVE-label shortcut closes this step.
3. **Separate reviewed activation.** Confirm source/version watchdog compatibility,
   additive `broadcast-registry-v1` migration and `BROADCAST_REGISTRY` binding;
   explicitly set the registry flag to `1` and retain the reviewed seven-code
   allowlist. Preserve existing registry state, flags, secrets, local source
   choices and FPL. No new account, spending or local scheduled job is part of
   activation. Do not infer deploy permission from completion of local tests.
4. **Cloud persistence/cadence receipt.** Observe the real endpoint and later
   normal five-minute cron plus bounded alarm continuation. Verify original
   source receipts, actual per-provider counters and next attempts; no duplicate
   charge/reset on repeated refresh, failure or disable/re-enable. Confirm one
   provider failure cannot remove another's accepted records. Mac metadata
   success and synthetic calls do not satisfy this gate.
5. **Jet private installation and real source tests.** Root uses one sequential
   signed gate and in-place install with before/after preference/version checks.
   Use a fresh authoritative currently eligible PL, UCL or cricket fixture;
   do not reuse expired test pins. Normal Watch must reach its associated exact
   source through the real adapter/relay and picker. Observe the correct
   programme and at least 90 seconds of actual advancing decoded video, then
   pause/resume, native fullscreen/Done and PiP. Missing fixture or descriptor is
   pending/unavailable, not a playback pass. Each sport/competition remains a
   separate qualification; UCL requires its real live window.
6. **Outage drill and cleanup.** Within the approved isolated test gate, make a
   primary-family lookup fail while accepted official fixtures and enabled
   independent source evidence remain. Verify normal Watch can obtain a fresh
   independent descriptor without a stale URL or mismatched fixture; restore
   any temporary test state. Record actual results, remaining unknowns and
   protected-input checks. Remove only owned build/private test output and
   temporary keep-awake processes. Leave the normal app intact.
